- [Legacy role normalization](legacy-role-normalization.md) — stale DB role (company_admin) after a code rename 403s every gated write (whole capture engine); normalize at the auth boundary so it self-heals. 403≠OCR bug.
- [Mobile global query invalidation](mobile-query-invalidation.md) — Orval hooks don't invalidate; a global MutationCache.onSuccess in app/_layout invalidates all queries so dashboard/lists stay fresh without restart. Don't add per-call invalidation.
- [Drizzle PATCH empty-set 500](api-patch-empty-set.md) — every PATCH route must guard empty updateData (400, not 500) before db.update().set({}) and destructure req.body ?? {}; bad/empty input is a client error.
- [Mobile i18n + RTL + OCR language](mobile-i18n.md) — EN/AR locale parity is load-bearing; RTL is JS-driven (no reload); OCR `original` never stores a translation; offline scans translate by capture-time language.
- [Mobile batch-store OCR lifecycle](mobile-batch-ocr.md) — setBatchCaptures must NOT clear ocrResults (background OCR fires setBatchOcrResult before setBatchCaptures); clear only in clearBatchCaptures (end of session). batch-review must poll for "pending" status before falling back to sequential OCR.
- [Mobile scroll flexGrow](mobile-scroll-flexgrow.md) — all vertical ScrollView/FlatList/KeyboardAwareScrollView need flexGrow:1 in contentContainerStyle or drag-over-empty-space does nothing; also add keyboardShouldPersistTaps="handled". Remove scrollEnabled={list.length>0} gates (they break pull-to-refresh on empty state).
- [Mobile scan & mutation performance](mobile-performance.md) — server was never the "30s"; never await Gemini on a save response; deferred DB scores don't invalidate RQ; set camera pictureSize (don't full-sensor+shrink); thinkingBudget:0; optimistic onMutate.

- [Mobile PIN fallback pattern](mobile-pin-fallback.md) — PinPad uses resetSignal (increment) not error bool; SecureStore PIN stored plaintext (TEE-encrypted, equivalent to hash); refreshPinAvailability() must be called after save/clear so overlay reacts without restart.
- [Soft-delete parity traps](soft-delete-parity-traps.md) — hard→soft conversion: softDelete must hand-replicate the onDelete cascade in a txn; UPDATE helpers called after a precheck (e.g. async scorer) need an isNull(deletedAt) guard or they write to/notify dead rows.
- [MFA company-required policy hook](mfa-required-policy-hook.md) — computing mfaNeeded but only challenging when user.mfaEnabled bypasses company-required MFA for unenrolled users; split the gate, issue no operational token, record no failed attempt.
- [OpenAPI optional-field ripple](openapi-optional-field-ripple.md) — loosening a shared response field (e.g. AuthResponse.token optional) breaks EVERY codegen consumer incl. mobile; run full `pnpm run typecheck` and guard each call site.
- [Refresh-token family revocation](refresh-rotation-revoke.md) — revoke a refresh family ONLY on proven replay (presented secret matches prior hash) + look up by unguessable familyId, else `<guessedId>.<garbage>` is an unauthenticated forced-logout DoS.
- [Login rate limiter counts failures only](login-ratelimiter-skip-success.md) — per-IP credential guard must skipSuccessfulRequests; counting successful logins false-positives shared-IP/NAT and breaks live integration suites (cumulative localhost logins → 429).
- [RBAC grant subset guard](rbac-grant-subset-guard.md) — assigning custom roles needs a permission-subset check vs the caller's own perms, not just base-role rank; else self-escalation via custom roles.
