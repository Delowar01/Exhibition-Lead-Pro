# Project File Map

A searchable **feature → files** map for Lead Capture Pro (repo: "Card Scanner Pro"). Every path is workspace-relative and verified against the current tree.

Use this to jump from a product area to the API route, service, schema table, web page/component, mobile screen, and tests that implement it. Paths that do not exist for a given area are marked `—`.

## Conventions

- **API routes** live in `artifacts/api-server/src/routes/`.
- **Services** live in `artifacts/api-server/src/services/`; shared helpers live in `artifacts/api-server/src/lib/`.
- **Schema tables** live in `lib/db/src/schema/` (Drizzle; synced via `drizzle-kit push`, no versioned SQL migrations).
- **Web pages** live in `artifacts/web-app/src/pages/` (admin portal + platform owner); shared components in `artifacts/web-app/src/components/`.
- **Mobile screens** live in `artifacts/mobile/app/` (Expo Router); shared logic in `artifacts/mobile/lib/` and `artifacts/mobile/components/`.
- **API tests** are in `artifacts/api-server/test/` (vitest); **web tests** in `artifacts/web-app/e2e/` (Playwright); **mobile tests** in `artifacts/mobile/lib/*.test.ts` (vitest).
- Generated API clients (Orval) live in `lib/api-client-react/src/generated/` (`api.ts`, `api.schemas.ts`); OpenAPI source is `lib/api-spec/`.

## Notes

- **Scope removals (must not be reintroduced on mobile):** full mobile administration, mobile AI Command Center, mobile Workflow Intelligence, mobile Executive Intelligence, and Contact AI on mobile. NFC capture is intentionally **kept** on mobile (`artifacts/mobile/app/capture-nfc.tsx`, `artifacts/mobile/lib/nfc.ts`).

All AI calls route through the Enterprise AI Layer (`artifacts/api-server/src/ai/runner.ts` + `artifacts/api-server/src/services/ai.service.ts`).
- **Schema sync:** the database uses `drizzle-kit push` from `lib/db/src/schema/` — there are **no versioned SQL migration files** in the repo.
- **Web dev-only screens:** `artifacts/web-app/src/pages/admin/DesignSystem.tsx` is a design-system reference page (not a product feature).
- **Mobile dev-only screens:** `artifacts/mobile/app/dev-perf.tsx` and `artifacts/mobile/app/sync.tsx` are developer utilities.
