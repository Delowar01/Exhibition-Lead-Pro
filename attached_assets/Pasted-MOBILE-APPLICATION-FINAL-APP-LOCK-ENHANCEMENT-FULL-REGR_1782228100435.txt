PART 1 – APP LOCK ENHANCEMENT
1. App PIN Fallback
Current Status

Biometric Unlock has been implemented.

Now add a secure App PIN fallback.

Requirements

When a user enables Biometric Unlock for the first time:

Verify biometric authentication.
After successful verification, prompt the user to create a 6-digit App PIN.
Confirm the PIN before saving.
Store the PIN securely using the device's secure storage.

Do not store the PIN in plain text.

PIN Unlock Flow

When the application is locked, users should be able to unlock using either:

Face ID / Fingerprint
App PIN

If biometric authentication fails or is unavailable:

Automatically allow PIN entry.

Failed PIN Attempts

Protect against brute-force attacks.

Example:

Maximum 5 incorrect attempts

Then:

Require biometric authentication again (if available)
Or temporarily lock the App PIN for 30 seconds
PIN Management

Inside Settings add:

Change App PIN

Workflow:

Verify existing biometric or PIN
Enter new PIN
Confirm new PIN
Disable PIN

When Biometric Unlock is turned OFF:

Ask:

Do you also want to remove your App PIN?

Options:

Keep PIN
Remove PIN
2. Automatic App Re-Lock
Current Issue

The application currently locks only when returning from the background.

If the device screen turns off while the app is open, sensitive information may briefly appear before authentication.

This is a security gap.

Required

Automatically lock the application whenever:

Device screen turns off
Device is manually locked
Device auto-lock activates
Application returns from the background after the configured timeout

Authentication must occur before any application content becomes visible.

Lock Timeout

Keep the default timeout:

30 seconds

Design the architecture so future timeout options can be added without redesign:

Immediately
15 Seconds
30 Seconds
1 Minute
5 Minutes
Security

Do not rely only on AppState.

Monitor all relevant lifecycle events to ensure sensitive information is never exposed during:

Screen off
Device sleep
Device wake
App resume
User Experience

Display a professional unlock screen with:

Lead Capture Pro logo
Unlock with Biometrics
Enter App PIN

Maintain a clean, premium design consistent with the application.
