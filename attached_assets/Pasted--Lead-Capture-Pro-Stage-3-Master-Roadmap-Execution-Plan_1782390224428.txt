# Implementation Rules

The roadmap must follow these principles:

* No regressions.
* Preserve backward compatibility.
* Preserve APIs unless new APIs are required.
* Preserve existing authentication.
* Preserve enterprise privacy.
* Preserve multi-tenant isolation.
* Follow contract-first development.
* Follow existing architectural patterns.

Avoid unnecessary architectural refactoring.

---

# Execution Strategy

After generating the complete roadmap:

1. Present the full Stage 3 roadmap.
2. Recommend the optimal implementation order.
3. Explain why each phase depends on previous phases.
4. Identify any phases that can run in parallel.
5. Recommend the appropriate Replit Agent mode (Power, Economy, or Lite) for each phase.
6. Wait for approval before implementing the next phase.

Do not begin coding until the roadmap has been reviewed and approved.

The roadmap should serve as the master execution plan for the remainder of Stage 3.
