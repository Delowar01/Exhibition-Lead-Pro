# 10. PIPELINE CURRENCY LOCALIZATION

## Current Issue

Pipeline values are always displayed in **USD**.

The application already allows the user to select a **Country** in Settings.

The Pipeline should automatically use the currency associated with the selected country.

### Required Country Mapping

* KSA → SAR
* UAE → AED
* QAT → QAR
* OMN → OMR
* KWT → KWD
* BHR → BHD
* EGY → EGP
* MAR → MAD

### Requirements

* New Pipeline opportunities should default to the selected country's currency.
* Dashboard Pipeline Value should use the correct currency.
* Reports should use the correct currency.
* Existing Pipeline records should retain the currency they were created with.
* Only newly created opportunities should use the updated default currency after the country setting changes.

Design the currency system to support future multi-currency functionality without database redesign.
