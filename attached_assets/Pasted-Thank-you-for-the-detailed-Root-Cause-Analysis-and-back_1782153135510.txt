# 7. BATCH SCAN MODE – WORKFLOW IMPROVEMENT

↓

Tap Done

↓

OCR starts

↓

Review Screen

↓

This causes unnecessary waiting during review.

---

## Required Workflow

Capture Images Continuously

↓

Each image is immediately added to a background processing queue.

↓

OCR, AI Extraction, Duplicate Detection, and GPS processing begin automatically while the user continues scanning.

↓

User taps Done.

↓

The review screen opens with all (or nearly all) images already processed.

↓

User only reviews, makes corrections if necessary, and taps Save.

Moving to the next review should be instant and must not trigger OCR processing again.
