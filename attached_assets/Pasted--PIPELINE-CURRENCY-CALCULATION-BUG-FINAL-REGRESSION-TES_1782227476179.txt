# CRITICAL ISSUE – PIPELINE CURRENCY CALCULATION

## Current Result

The Pipeline currency conversion is not calculating correctly.

### Example

I currently have **4 Pipeline opportunities**, all stored in **USD**.

* USD 35,000
* USD 25,000
* USD 15,000
* USD 10,000

Total:

**USD 85,000**

My selected country is **Saudi Arabia (SAR)**.

Using the standard exchange rate (approximately **1 USD = 3.75 SAR**), the dashboard should display approximately:

**SAR 318,750**

However, the Dashboard currently displays:

**SAR 260.4K**

This indicates that either the currency conversion or the total calculation is incorrect.

---

# REQUIRED INVESTIGATION

Perform a complete Root Cause Analysis.

Verify:

* Are all Pipeline records included in the calculation?
* Is every opportunity converted individually before summing?
* Is the total converted after summing instead of converting each record?
* Are some records already stored in SAR and converted again?
* Are Won/Lost opportunities being incorrectly excluded?
* Is dashboard caching returning stale totals?
* Is the selected country being applied correctly?
* Is the dashboard using the same calculation as the Pipeline list?

Do not assume the exchange rate is the problem.

Identify the exact cause.

---

# REQUIRED BEHAVIOR

Every Pipeline record should retain its original currency.

For Dashboard display:

1. Read each Pipeline record.
2. Detect its stored currency.
3. Convert each record to the user's selected currency.
4. Sum the converted values.
5. Display the final total.

This architecture is required for future multi-currency support.
