---

# 1. QR CODE / LINKEDIN QR CONSOLIDATION

## Current Design

The application currently has two separate capture methods:

* QR Code
* LinkedIn QR

This creates unnecessary complexity because LinkedIn QR is simply another type of QR code.

---

## Required

Merge both capture methods into a single option.

Rename the capture method to:

## **QR Code / LinkedIn**

Remove the separate **LinkedIn QR** option completely.

---

## Intelligent QR Detection

When scanning, the application should automatically identify the QR code type.

Supported QR formats should include:

* LinkedIn Profile QR
* vCard QR
* MECARD
* Business Contact QR
* Standard Contact QR
* Website URL
* Company Website
* Plain Text QR (display for manual review)

No user selection should be required.

The application should determine the QR type automatically.

---

## LinkedIn QR Handling

If the scanned QR code is a LinkedIn profile:

* Detect that it is a LinkedIn QR.
* Extract the profile URL.
* Store the LinkedIn URL in the contact record.
* If additional information can be retrieved, populate the corresponding fields.
* If LinkedIn privacy restrictions prevent automatic extraction, preserve the LinkedIn URL and allow the user to complete the remaining fields manually.

The application should never fail silently.

---

## Acceptance Criteria

* Only one capture option exists:

  * **QR Code / LinkedIn**
* All supported QR formats are detected automatically.
* Contacts are created correctly.
* LinkedIn URLs are stored correctly.
* No duplicate QR scanning options remain in the UI.
