# 7. BATCH SCAN MODE – WORKFLOW IMPROVEMENT

## Current Workflow

Batch Mode

↓

Capture Images

↓

User taps **Done**

↓

OCR starts

↓

Review Screen

↓

Every time the user taps **Next**, the application processes the next image.

This creates unnecessary waiting during review.

---

## Required Workflow

Batch Mode

↓

Capture Images Continuously

↓

Each captured image is immediately added to the local processing queue.

↓

OCR, AI Extraction, Duplicate Detection, and GPS processing begin **in the background** while the user continues scanning.

↓

User taps **Done**

↓

Processing should already be complete (or nearly complete) for all captured images.

↓

Review Screen opens immediately.

↓

User simply reviews each extracted lead.

↓

Edit if necessary.

↓

Tap **Save**.

↓

Next review opens instantly without additional OCR processing.

---

## Requirements

During capture:

* OCR runs in the background.
* AI Extraction runs in the background.
* Duplicate Detection runs in the background.
* GPS Capture runs in the background.

The user must never wait during the review stage for OCR processing.

Only image capture should occur while the camera is open.

Background processing should utilize idle time during scanning.

---

## Acceptance Criteria

* User can capture a large batch of business cards continuously.
* Processing occurs while scanning.
* Review screen opens almost instantly after tapping **Done**.
* Moving between review screens does not trigger additional OCR processing.
* Review becomes a validation step only, not a processing step.
